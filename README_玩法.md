# 生死轮盘 · Bar Duel v5 —— 玩法说明

中文 2D 吧台对坐轮盘对决：**玩家 李炎（你） vs 五个对手**，一关一场，玩家 HP 140，Boss HP 见下表。
先让对方 HP 归零者获胜。v5：转盘改回正圆并放大、左侧界面精简、对手改为网格变形立绘（呼吸 / 摇摆 / 抽搐 / 中枪后仰）。

启动方式：双击桌面「生死轮盘」快捷方式，或运行：

```
D:\Godot\Godot_v4.7.2-stable_win64.exe --path "D:\Godot\Projects\生死轮盘"
```

---

## 一、操作

| 操作 | 键位 / 鼠标 |
| --- | --- |
| 开始 / 进入对决 / 继续 | `Enter`，或点击任意处 / 按钮 |
| 转动转盘 | `空格`，或点击「转动转盘」按钮 / 转盘中心「转动」 |
| 使用道具 | 点击左侧道具槽，或按 `1` / `2` / `3` |
| 槽满时替换 / 放弃 | 点击按钮，或按 `1` / `2` / `3` / `ESC` |
| 结束回合 | `Enter`，或点击「结束回合」 |
| 玩法说明 | `F1`，关闭按 `F1` / `ESC` |

> 每回合只能转 **一次**；转完结果立即生效，然后可以用 **1 个** 道具（可选），再结束回合。
> 对手同样只转一次，但每一步会以 0.8–1.2 秒的节奏逐步演示。
> **处决**：当对方 HP 已低于 25%，而你的弹巢里还有至少 3 发子弹，开枪伤害变为 ×1.5，并触发红灯与重震。

## 二、回合流程与状态机

`TITLE → BOSS_INTRO → PLAYER_TURN → SPINNING → RESOLVE → ITEM_PHASE → AI_TURN → GAME_OVER`

1. 标题页按 `Enter` 开始。
2. 每关先显示 Boss 登场卡（名字、绰号、一句台词、特殊规则），点击或回车进入。
3. 顶部常驻「当前该做什么」；右下角日志逐条解释结算原因。
4. 玩家：转盘 → 结算 → 可用 1 个道具 → 结束回合。
5. AI：维护状态 → 特殊规则（偷道具 / 回血）→ 可能用道具 → 转盘 → 结算 → 轮到玩家。
6. 一方 HP 归零：显示本关战绩（回合数、造成伤害、最高单次伤害、剩余 HP），继续下一关或结算全局。

## 三、转盘 36 格（以第 1 关为例）

| 格子 | 数量 | 效果 |
| --- | --- | --- |
| 空 | 12（约 33%） | 什么也没发生；连续 3 次空转后下一次伤害 +10% |
| ? 未知 | 3 | 盘面上只显示问号，落地才知道真面目：子弹 / 道具 / 回血 / 双倍 / 诅咒 |
| 弹 | 7 | 弹巢 +3（最多 8 发） |
| 枪 | 4 | 弹巢全部打出，每发 30 伤害；空巢则走火自扣 5 HP |
| 具 | 4 | 随机获得一件正面道具 |
| 疗 | 3 | 回复 15 HP |
| 咒 | 1 | 受到 10 点伤害 |
| 双 | 1 | 下一次伤害 ×2 |
| 伤 | 1 | 走火自伤 20 HP |
| 胎 | 0 | 获得负面道具「漏气的轮胎」 |
| 药 | 0 | 获得负面道具「劣质火药」 |

每个 Boss 的权重都写在 `res://data/bosses.json` 的 `wheel` 字段里，共 36 格，统一走同一个 RNG 抽取。
越往后「空」越多（第 5 关 16/36 ≈ 44%），负面格也逐步加回来；转盘大部分面积是空的，这就是心理战的核心。

## 四、道具（全部支持 Lv1–Lv3，重复获得升级）

| 道具 | Lv1 | Lv2 | Lv3 |
| --- | --- | --- | --- |
| 祖国人体验卡 | 45 真实伤害 | 65 | 90 |
| 火箭筒 | 35 伤害 / 自伤 5 | 50 / 8 | 70 / 10 |
| 哆啦A梦 | 跳过 1 回合 | 跳过 1 回合 | 跳过 2 回合 |
| 大罗金仙体验卡 | 免伤 1 回合 + 双倍 | 免伤 2 回合 + 双倍 | 免伤 2 回合 + 双倍 + 回 15 HP |
| 丧尸病毒 | 8 × 3 回合 | 10 × 3 | 12 × 4 |
| 防弹衣 | 挡 1 次 | 挡 1 次并反弹 10 | 挡 2 次 |
| 漏气的轮胎（负面） | 1 回合不能转盘 | 2 回合 | 3 回合 |
| 劣质火药（负面） | 下次开枪减半 | 只剩 40% | 只剩 30% |

道具槽只有 3 个。槽满时再获得道具会弹出三选一：替换槽位 1 / 2 / 3，或按 `ESC` 放弃——不会静默丢弃。
负面道具不能主动使用：轮胎在你的回合开始时自动扣减等级并封锁转盘，火药在你下一次开枪时自动生效。

## 五、五关 Boss

| 关卡 | Boss | HP | 特殊规则 |
| --- | --- | --- | --- |
| 1 | 醉汉老张（三杯倒的酒鬼） | 100 | 「空」最多（42%）；他自己开枪时手抖，一半子弹打偏 |
| 2 | 红发荷官（笑里藏刀的女人） | 130 | 每 3 个回合偷你 1 件道具 |
| 3 | 哑巴枪手（不说话的枪） | 150 | 命中后追加 5 点流血 × 3 回合；「枪」格更多 |
| 4 | 疯批医生（疯人院主治） | 170 | 每 3 回合回复 20 HP |
| 5 | 轮盘之主（赌桌的主人） | 200 | 开局自带 Lv2 防弹衣；每次空转回 3 HP |

台词库在 `res://data/dialogue.json`，每个 Boss 覆盖六种事件：空转 / 自己被击中 / 击中你 / 低血量 / 获胜 / 失败，
台词在屏幕右上气泡里逐字显示（0.03 秒/字），对手用金边气泡。

## 六、氛围与反馈

- 对手为 AI 生成的写实暗黑立绘（深阴影、伤口、污渍），边缘做了羽化与压暗，直接坐在桌子对面；
  立绘以 **18×20 网格实时变形**：呼吸、头肩摇摆、神经质抽搐、中枪后仰、低血量颤抖，血量越低越偏血色。
- 场景为脏酒吧实景底图：剥落墙皮、裸砖、单只吊灯、烟雾、桌上血污；转盘为正圆，立在桌子中央。
- 暗角、灯光闪烁、胶片噪点、低血量红色脉动；开枪屏幕震动 + 闪光。
- 音效全部程序生成：转盘滴答、枪声、空枪咔哒、命中闷响、心跳（低血量加速）、环境低频嗡鸣。
- 背景音乐：32 秒无缝循环的压迫感配乐（低频 drone + 心跳 + 不协和金属音），随游戏自动播放。
- 每次转盘落地，屏幕中央弹出大号结果横幅：金色「你 → …」，血红「对手名 → …」，未知奖励会标注「未知奖励 → …」。
- 玩家 HP 低于 45% 时心跳与红色脉动开始增强。
- 通关纪录写入 `user://progress.cfg`，标题页显示历史最佳关卡与累计通关次数。

## 暗押质疑

每关可在自己的转盘阶段点击暗押按钮或按 Q。对手声称木牌下有红印，举止只是线索，也可能误导。质疑成功对手扣 18 点生命，失败自己扣 18 点。每关只能结算一次，不消耗转盘次数。

## 第 2 关 暗骰赌桌
按空格或点击掷骰。高点装一格，同点重掷。先装满六格获胜。连续三次六点且在决胜掷中胜出，可提前结束。双方规则相同。原第二至第五关顺延。
